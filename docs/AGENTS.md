# AGENTS.md

本文件约束 `docs/` 目录中的 Markdown 文档。`CLAUDE.md` 是指向本文件的符号链接。
仓库级协作规则见 [根目录 AGENTS.md](../AGENTS.md)，开发、Markdown 与 Git 规范见
[CONTRIBUTING.md](../CONTRIBUTING.md)。

## 文档归属

- 根目录 `README.md` 是项目介绍、快速开始和目录概览的权威位置。
- 根目录 `workflow.md` 是数据流水线、工作流阶段和配置用法的权威位置。
- `docs/` 用于补充无法自然归入上述入口的专题说明。新增页面前先检查是否已有合适的维护位置，
  不复制已有命令、目录树或规则。
- 命令示例以脚本当前 `--help` 和 `tools/cfg/` 配置为准；修改共享行为后同步检查相关示例。
- 当前项目没有 Markdown 站点生成器或自动生成的 API 参考页。不要假设页面由外部构建流程生成，
  也不要为文档改动引入新的生成工具。

## Markdown 约定

- 文档使用简体中文，标题按层级递进，段落聚焦单一主题；代码块标明语言。
- 仓库内链接使用相对路径，并确认目标文件存在。链接以当前 Markdown 文件所在目录为基准。
- 命令示例注明执行目录、必要前置条件，以及是否会修改文件或数据。
- 规则和步骤应可直接执行；易变的参数优先引用权威配置或脚本帮助，不在多处维护副本。
- 细节样式遵循根目录 [CONTRIBUTING.md](../CONTRIBUTING.md) 的 Markdown 约定。

## 校验

从仓库根目录检查文档改动：

```powershell
git diff --check
```

同时核对新增或修改的本地链接、命令路径和配置名。涉及工作流示例时，从仓库根目录用对应配置运行
`.conda\python.exe tools\workflow.py --config <配置文件> --dry-run` 检查命令；普通文档改动不运行项目测试套件。
